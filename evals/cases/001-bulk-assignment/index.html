001 — Bulk Assignment

Reviewer context and assertions stay on this page; the embedded prototype contains only product UI.

Requirement brief

Goal

Allow a field-operations coordinator to reassign multiple already-selected work orders to one technician quickly, while keeping the result clear and recoverable.

Background

Field-operations coordinators triage a shared work queue throughout the day. They often select several work orders that need the same technician and then perform a batch assignment while remaining in the queue context.

Current state

The queue already supports multi-selection and Assign, but the current flow re-establishes target context and adds decision/confirmation steps even though the selected work orders and Assign intent are already known.

Optimization direction

Feature optimization

Expected behavior

  • Reuse the already-selected target set.
  • Keep Assign a concrete command, not a capability catalog.
  • Ask only for the unresolved technician.
  • Commit directly after technician choice.
  • Show consequence and Undo.
  • Preserve selection on dismissal.
  • Adapt presentation without changing semantics.
  • Keep all reviewer/prototype explanations outside the product surface.
